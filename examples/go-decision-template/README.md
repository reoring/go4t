# One decision in go4t inside an ordinary Go package

The smallest way to adopt go4t: keep your Go package, move **one function**
into a `.gt` file, generate Go from it, and call it. Callers of the package see
only Go types. This directory is a complete Go module you can copy.

```
decide/decide.gt   the decision and its laws (the only go4t you write)
decide/*.go        generated by `go generate`, committed
generate.go        the //go:generate line
freshness.go       Go API: time.Duration / time.Time in, a Go enum out
freshness_test.go  ordinary Go table test of that API
```

## Try it

From this directory (the module's `replace` points at the checkout root):

```sh
go run github.com/reoring/go4t/cmd/go4t check decide/decide.gt   # exhaustiveness + laws, for every input
go generate ./...                                               # regenerate decide/*.go
go test ./...
```

## Copy it into your repository

1. Copy `decide/decide.gt` and `generate.go` next to the Go code that needs the
   decision. Replace the body of `decide.gt` with your function. Keep its
   inputs as sums (`NoTtl | InvalidTtl | TtlNanos(Int)`), not as a value plus a
   flag: the point is that every combination is visible and matched.
2. Depend on the compiler as a tool so the version is pinned in `go.mod`:

   ```sh
   go get github.com/reoring/go4t@latest
   ```

   and remove this example's `replace` line.
3. `go generate ./...`, then commit `decide/*.go`. Ordinary `go build` needs no
   generation step and no go4t on the builder.
4. In CI, fail on drift and on a broken law:

   ```sh
   go run github.com/reoring/go4t/cmd/go4t check decide/decide.gt
   go generate ./... && git diff --exit-code
   ```

## What the Go side looks like

A sum type becomes a Go interface with one struct per constructor, named
`<Type><Constructor>`; positional fields are `F0`, `F1`, …; `Int` is `int64`.
An exported function keeps its name capitalized, except that a function whose
name would collide with a type gets an `Fn` suffix — here `freshness` returns
`Freshness`, so the function is `decide.FreshnessFn`:

```go
switch result := decide.FreshnessFn(ttl, observedAt, now.UnixNano()).(type) {
case decide.FreshnessFresh:
    return Fresh, time.Duration(result.F0)
case decide.FreshnessStale:
    return Stale, 0
// … one case per constructor
}
```

`freshness.go` keeps that switch, and the projection from Go's `nil`/zero
conventions to the named cases, in one place. The projection is ordinary Go and
is covered by the Go test; the decision is covered by the laws. The full
mapping rules are in [SPEC §8.7](../../SPEC.md#87-exported-go-api) and
[docs/go-interop.md](../../docs/go-interop.md).

## What the laws say

`go4t check` proves each `law` in `decide.gt` for all inputs, including the
boundary a table test usually misses (`now == at + ttl` is stale, not fresh).
The elapsed-time law carries a `requires` clause: under wrapping `Int`,
"stale once the TTL has elapsed" is only true while `at + ttl` cannot overflow,
and the law says so instead of hiding it.

For a larger shape — a controller whose observe and apply stay in Go — see
[node-drain-controller](../node-drain-controller); for the conversion rules
exercised one by one, see [go-shell](../go-shell).
