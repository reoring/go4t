# Code generation quality

## Specification delta

No grammar, source types, prelude signatures, or runtime ABI change. Values and explicit parameters still use `any`; type-class dictionaries retain their existing interfaces.

Direct self calls in a function's result position are lowered to a Go `for` loop. Result position includes either `if` branch, each `match` arm (including guarded arms), and the final expression of nested blocks. Every new explicit argument is evaluated left-to-right into its own `any` temporary before simultaneous parameter reassignment and `continue`. Source-level parameter bindings are fresh each iteration, so shadowing and closures capturing earlier arguments retain immutable-value semantics.

Only direct references to the same function binding qualify. Non-tail calls, calls through aliases, mutual recursion, calls inside other lambdas or `do` continuations, and calls to a shadowing binding remain ordinary calls. Dictionary parameters pass through unchanged. A polymorphically recursive call that selects different dictionaries remains an ordinary call rather than incorrectly reusing the current dictionaries.

Top-level functions are handled by `planTail` / `loopBody`. `namedLambda(name string, lambda *ast.Lambda) string` is the corresponding codegen entry point for a binding already known to be recursive; ordinary nonrecursive lets must not use it because their initializer can refer to an outer binding with the same name.

`fold[A, B](xs List[A], init B, f func(B, A) B) B` already uses a self tail call. `length[A](xs List[A]) Int` and `reverse[A](xs List[A]) List[A]` already delegate to that fold. All three therefore run with bounded stack without any prelude source changes.

Generated Go has `//line <file>:<line>` before function declarations, function literals and match arms. Filenames come from the owning `ast.File.Name`; line numbers come from AST positions. Generated constructor/shape/ordering helpers use their associated type or constructor declaration. Result-expression markers additionally keep panic locations from drifting over synthetic bindings. Synthetic test ASTs without filenames or positive line numbers emit no invented location. A newline in a filename is rejected with `source filename contains a newline` rather than allowing directive injection.

`Generate` returns go/format-formatted output. On a formatting failure it returns the unformatted generated bytes and the error `format generated Go: <underlying error>`, allowing callers to inspect the failed output without concealing a generator bug.

## Regression coverage

- Loop shape, simultaneous reassignment via temporaries, unchanged dictionary parameters, and conservative treatment of dictionary-changing recursion.
- Non-tail calls and lexical shadowing, named recursive lambda lowering, guarded match tails, and nested block tails.
- Runtime parameter swapping, shadowed parameters, and closures retaining prior-iteration values.
- A `go run` test builds one million list elements, folds their sum, computes length, reverses the list, and checks the reversed list. It sets Go's maximum goroutine stack to 256 KiB to distinguish actual constant-stack lowering from Go's automatic stack growth. Each subprocess has a 120-second context deadline and five-second pipe-drain bound.
- Formatting idempotence, immediately preceding function directives, source positions for match arms, preserved bytes on formatting failure, and a division-by-zero panic trace containing `panic.gfx:5`.

CI sets up Go from `go.mod`, runs `go vet ./...` and `go test ./...`, and executes every `examples/*/main.gfx`. Example stdin comes from `input.txt` when present (otherwise `/dev/null`); `args.txt` supplies whitespace-separated literal arguments without shell evaluation. `examples/wc/args.txt` contains `3`.

## Parallel integration

The local-recursion slice owns recursive-binding recognition and local function declaration AST support. Its recursive-let and local-function assignment sites must call `namedLambda` with the source name. Its local `FuncDecl` statement case belongs in `tailStatements`, preserving the tail plan through the remaining statements; such a declaration also shadows a same-named enclosing local function in `planTail`.

## Deviations

No source-language deviations. Dictionary-changing polymorphic recursion is deliberately not eliminated because the contract requires unchanged dictionary parameters. `length` and `reverse` are unchanged wrappers around the already tail-recursive `fold`, rather than introducing duplicate accumulator implementations.

None.
