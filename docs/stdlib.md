# Standard library reference

Signatures below are inventoried from every top-level declaration in
`std/**/*.gfx`, in module/source order. `docs/stdlib_inventory_test.go` parses the
embedded sources and requires each declaration signature/name, each constructor,
and every class method to appear in its owning module's table with semantics and
a boundary column. Private helpers are deliberately included, **not** public APIs.
Instances generated by a source `deriving` clause are listed separately.

Use `import "std/list"` then `list.sort(xs)`. Only the fixed names in
[SPEC §2.3](../SPEC.md#23-implicit-prelude-and-shadowing) are implicit; import
`std/prelude` for `prelude.pure`, `prelude.bind`, `prelude.fmap`,
`prelude.foldr`, `prelude.traverse`. Import aliases do not rename operations:
`map.mapInsert`, not `map.insert`. Instances from the loaded graph are global.

Arguments are strict, even defaults and functions passed to deferred IO. All
collections are immutable. Indexes/counts use Int; string indexes and widths are
runes, not bytes/graphemes. Huge positive allocations remain host-resource
bounded. For the combined language boundary tables see
[SPEC §10](../SPEC.md#10-boundary-behaviour).

## Builtin types (not source declarations)

| Type / kind | Semantics | Boundary |
| --- | --- | --- |
| `Int : *` | Signed int64 arithmetic. | Wraparound; division/remainder by zero panic. |
| `Float : *` | IEEE binary64. | No Int coercion; NaN equality differs from NaN-low Ord. |
| `String : *` | Go text string. | Rune APIs and byte equality/order are distinct. |
| `Bool : *` | true or false. | Both literals form an exhaustive match. |
| `Unit : *` | Sole value from unit(). | Eq/Debug, no Show/Ord. |
| `IO : (*) -> *` | Deferred fallible action. | Construction is strict; running is deferred. |
| `Fiber : (*) -> *` | Cached concurrent outcome. | No standard class instances or cancellation. |
| `Map : (*, *) -> *` | Persistent AVL map. | Comparator EQ identifies keys; consistent ordering required. |
| `Set : (*) -> *` | Persistent AVL set. | Comparator-equivalent elements deduplicated. |
| `Array : (*) -> *` | Immutable indexed sequence. | Copy on write/push/sort, Option reads. |
| `TupleN : (*, ...) -> *` | Immutable N-tuple, N ≥ 2. | General tuple syntax; ordinary display/order instances only for pairs, JSON every arity. |

## Worked examples

Save either block as a separate `main.gfx` beneath the checkout and run
`gofx run main.gfx` (or `go run ./cmd/gofx run main.gfx` from the root).

```gofx
package main
import "std/list"
import "std/string"
func main() IO[Unit] {
  string.words("pear apple pear") |> list.nub |> list.sort |> string.join(", ", _) |> println
}
```

```gofx
package main
import maps "std/map"
import "std/array"
func main() IO[Unit] {
  let counts = maps.mapFromList([("pear", 2), ("apple", 1)])
  let original = array.arrayFromList([10, 20])
  let changed = array.arraySet(original, 1, 99)
  println("${counts} ${original} ${changed} ${array.arrayGet(original, -1)}")
}
```
