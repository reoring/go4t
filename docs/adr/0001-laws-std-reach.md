# Standard-library law taint reach

Generated by `GO4T_UPDATE_TAINT_REACH=1 go test ./laws/ -run TaintReach`; without the variable the test asserts byte equality.

## Scope and interpretation

Every source top-level function (including externs) and checked instance method is listed; derived methods are included after types.Check expansion. Class signatures and constructors are not functions. **law-eligible means untainted by this inventory**, not proved terminating or provable with the current tactics. All syntactic branches and local function/lambda bodies are inspected, even unreachable ones. Nonzero integer literals and their unary negatives are the only safe divisors. Type inspection includes nested algebraic fields, matching the evaluator's rejection of nested Float and IO.

The whitelist is the ten std/prelude externs plus all 32 std/string externs accepted by laws/primitives.go and laws/strings.go; a similarly named user extern is not trusted. String externs fold only when every argument is constant, using the real go4t/rt implementations. Direct reasons take precedence over transitive reasons: signature IO, signature Float, unlisted extern, then the first body IO/Float/division occurrence in AST order. Concrete checked dictionaries add dependencies on selected methods; dictionary arguments conservatively add all their methods. Abstract dictionary parameters and function parameters are conditional obligations, **not** dependencies on every possible instance: callers must supply eligible implementations. Recursion alone is not taint. Transitive reasons use the shortest discovered tainted-callee path with lexical ties.

## Decision-core judgement

ADR 0001's reach includes constructor case analysis, Bool guards, Int arithmetic and first-order list induction; eligibility does not remove its order-reasoning, accumulator-generalization, termination or higher-order-quantification restrictions. README lines 79–96 describe approval and attachment controllers as pure Decide(Observed) Action logic with constructor-based evidence, TTL and timestamp states. That style remains inside this taint boundary when observations are already parsed and effects stay in the Go shell.

List structure, filtering, folds, append, Option (in std/prelude) and Result combinators are largely eligible, conditional on their callbacks/dictionaries. Int/Bool/String Eq/Ord/Show basics and string concatenation stay eligible through the prelude whitelist. All std/string helpers, including trim/split/startsWith/contains/parseInt, are now eligible; symbolic calls remain opaque until their arguments are constants. **The typical helper set is not wholly eligible:** every std/map operation ultimately uses an unlisted runtime extern, as do list helpers that convert through arrays. Map/set/array require a separately designed normal form and remain outside the whitelist. Inspect runtime maps in the shell and pass algebraic observations or lists to the core. Float and IO stay outside.
